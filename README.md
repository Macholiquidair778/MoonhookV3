When you first open MoonhookV3, you'll see a clean interface with several main areas:

### Connecting Your Discord Account
1. **Find your Webhook URL**: Go to your Discord server → Channel Settings → Integrations → Webhooks → New Webhook → Copy URL.
2. **Find your Bot Token**: From your Discord Developer Portal → Your Application → Bot → Token → Copy.

Paste either of these into the appropriate field in MoonhookV3.

### Basic Operations

**Deleting a Webhook:**
